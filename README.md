タイトル：
  アニメ聖地巡礼マップ - AnimeAtlas

概要：
  日本に限らず、海外にも存在するアニメの聖地をマップ上に表示し、聖地巡礼を盛り上げるためのアプリです。
  このアプリには聖地マップモードと対戦モードが存在します。
  聖地マップモードでの検索には、マップでアニメを検索する方法と、アニメの画像から探す方法があります。
  対戦モードでは、１～５人で対戦が可能で、聖地のマップと画像が表示され、それがどこかを早押し４択で回答し、最も得点の高いものが勝利するものです。
  また、制覇記録を用意していて、聖地に足を運んだら、自分でチェックをいれることで、旅の記録のような使い方もできます。

使用技術：
　使用言語：Flutter/dart
 データベース：firebase

工夫した点：
 アニメ名を知らない人や、画像から検索したい人向けに画像検索モードを制作しました。
 また、画面が遷移すると背景に表示しているキャラも変化しますが、チラチラして目が痛くならないよう、なるべく早く切り替わるようにしました。
